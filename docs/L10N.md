## File Structure

```text
lib/l10n/
├── app_en.arb          # Template (source)
├── app_hi.arb
├── app_es.arb
└── ...

l10n.yaml               # Flutter gen-l10n config
```

Example `l10n.yaml`:

```yaml
arb-dir: lib/l10n
template-arb-file: app_en.arb
output-localization-file: app_localizations.dart
output-class: AppLocalizations
nullable-getter: false
```

## ARB Key Conventions

* snake_case keys: `alarm_config_title`, `home_create_alarm`
* Group by feature prefix: `alarm_*`, `home_*`, `settings_*`
* Keep strings short - UI space is limited on small screens

Example `app_en.arb`:

```json
{
  "@@locale": "en",
  "appTitle": "Nomad Alarm",
  "homeCreateAlarm": "Create Alarm",
  "alarmDistanceLabel": "Alert me when {distance} away",
  "@alarmDistanceLabel": {
    "placeholders": {
      "distance": { "type": "String" }
    }
  },
  "historyCompletedCount": "{count, plural, =0{No completed alarms} =1{1 completed alarm} other{{count} completed alarms}}",
  "@historyCompletedCount": {
    "placeholders": {
      "count": { "type": "int" }
    }
  }
}
```

---

## Plural Rules

Use ICU plural syntax in ARB for:
* Alarm counts
* Trip counts
* History entries
* Minutes/seconds (snooze, ETA)

Do not concatenate strings for plurals in Dart code.

## RTL Support

Arabic (`ar`) and future Hebrew require RTL layout.

Checklist:
* [ ] Use `EdgeInsetsDirectional` instead of `EdgeInsets.only(left/right)`
* [ ] Use `AlignmentDirectional`
* [ ] Test navigation back arrow mirrors correctly
* [ ] Map controls remain usable in RTL
* [ ] Notification actions layout verified

Enable in app:

```dart
MaterialApp(
  localizationsDelegates: AppLocalizations.localizationsDelegates,
  supportedLocales: AppLocalizations.supportedLocales,
);
```

## Date & Time Format

Use `intl` package with locale from `AppSettings.languageCode`:

| Format | Example (en) | Example (hi) |
|--------|--------------|--------------|
| Short date | Jul 28, 2026 | 28 जुल॰ 2026 |
| Time | 5:30 PM | 5:30 PM |
| Relative | 2 hours ago | 2 घंटे पहले |

Never hardcode date patterns.

## Units

Controlled by `AppSettings.useMetric`:

| | Metric | Imperial |
|---|--------|----------|
| Distance | m / km | ft / mi |
| Speed | km/h | mph |

Format in a single utility:

```dart
String formatDistance(double meters, {required bool metric, required String locale});
```

TTS voice messages must use same units as UI.

## Voice (TTS) Localization

`SpeechService` selects language:

1. User setting in App Settings
2. `auto` → system locale
3. Fallback → English

Message templates per locale in `lib/l10n/tts/`:

```text
lib/l10n/tts/
├── tts_en.dart
├── tts_hi.dart
└── ...
```

Example:

```dart
String approachingMessage(String distance, String destination) =>
  'Your stop is approaching. $destination in $distance.';
```

---

## String Guidelines

* Use plain language (commuters, not engineers)
* Avoid idioms that don't translate
* Keep button labels ≤ 20 characters where possible
* Permission explanations: full sentences, calm tone
* Error messages: actionable ("Turn on location" not "LocationException")

---

## Adding a New Language

1. Copy `app_en.arb` → `app_<code>.arb`
2. Translate all keys (do not leave English fallbacks in PR)
3. Add TTS template if voice supported
4. Test on device with locale changed
5. Update this doc and README
