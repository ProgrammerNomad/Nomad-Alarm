# Nomad Alarm

A **privacy-first, open-source location alarm** that wakes you before you reach your destination - perfect for train passengers, bus commuters, and travelers.

**No ads. No subscriptions. No login. No tracking.**

## Features (v3.1)

- Location alarms with background GPS and foreground notification
- Multi-provider maps, search, and routing (OSM default; optional BYO API keys)
- Home screen widgets, Quick Settings tile, Wear OS complication, Android Auto read-only nav
- Voice search, family alarm bundle share, backup/restore, Hindi / Arabic / Hebrew UI
- High contrast accessibility theme
